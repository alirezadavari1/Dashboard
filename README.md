## 💡 What is this?

> A **complete, fully offline** desktop app for Windows that bundles everything into one place, instead of juggling 6 different tools. No cloud server, no subscription, no internet required — everything lives on your own machine.

## ⚙️ Installation

### Prerequisites

```
✔ Node.js 18+
✔ yt-dlp (for the downloader module)
✔ ffmpeg (optional, for high-quality merging)
```

### Setup steps

```bash
# 1. Clone the repository
git clone https://github.com/USERNAME/REPO-NAME.git
cd REPO-NAME

# 2. Install frontend dependencies
npm install

# 3. Install server dependencies
cd server
npm install
cd ..

# 4. Run in development mode (web + electron together)
npm run electron:dev
```

<br/>

## 📦 Building the installer

Want a real `.exe` you can install on any Windows machine?

```bash
npm run electron:build
```

Once it's done:

```
📁 dist/
   └── 📄 Dashboard Setup x.x.x.exe   ← run this!
```

> ⚠️ **Note:** This step must be run on your own machine (with unrestricted internet access), not inside a limited sandbox.

<br/>

<details>
<summary><b>🧪 Unpacked mode (no installer) — for quick testing</b></summary>

```bash
npm run electron:build:dir
```

</details>
