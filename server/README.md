# سرور دانلودر (Downloader Backend)

این سرور، پشتیبان واقعی قابلیت «دانلودر» در داشبورد است. مرورگر به‌تنهایی
نمی‌تواند مستقیماً از اینستاگرام یا یوتیوب دانلود کند (به‌خاطر محدودیت‌های
CORS و سیاست‌های خود این پلتفرم‌ها)، بنابراین یک سرور کوچک محلی (Node.js)
این کار را انجام می‌دهد و پیشرفت دانلود را به‌صورت زنده به داشبورد می‌فرستد.

## پیش‌نیازها

1. **Node.js** نسخه ۱۸ به بالا
2. **yt-dlp** — برای دانلود از اینستاگرام و یوتیوب. سرور دیگر از بسته‌ی
   ناپایدار و منسوخ‌شده‌ی `yt-dlp-wrap` استفاده نمی‌کند؛ خودش مستقیماً
   برنامه‌ی `yt-dlp` را روی سیستم اجرا می‌کند. آن را یکی از این راه‌ها نصب کنید:
   - با pip (پیشنهادی): `pip install -U yt-dlp`
   - ویندوز: فایل `yt-dlp.exe` را از https://github.com/yt-dlp/yt-dlp/releases
     دانلود کرده و در PATH سیستم قرار دهید.
   - اگر هیچ‌کدام را نصب نکنید، سرور در اولین دانلود سعی می‌کند یک نسخه‌ی
     قابل‌حمل را خودش از گیت‌هاب دانلود کند (نیاز به اتصال اینترنت دارد).
3. **Deno** (به‌شدت پیشنهادشده) — از اواسط ۲۰۲۶، یوتیوب صفحات را با یک
   چالش جاوااسکریپتی محافظت می‌کند و بدون یک runtime جاوااسکریپت، yt-dlp
   اغلب با خطای «403 Forbidden» یا «Failed to extract any player response»
   متوقف می‌شود. نصب Deno این مشکل را برطرف می‌کند:
   - از https://deno.com یا با دستور: `winget install deno` (ویندوز) /
     `brew install deno` (مک) / `curl -fsSL https://deno.land/install.sh | sh` (لینوکس)
4. (اختیاری ولی پیشنهادی) **ffmpeg** برای ادغام صدا و ویدیوی کیفیت بالا —
   از https://ffmpeg.org/download.html یا `winget install ffmpeg`

سرور خودش هرکدام از این ابزارها را که روی سیستم پیدا کند به‌صورت خودکار
استفاده می‌کند؛ نیازی به تنظیم دستی مسیر نیست.

## نصب و اجرا

```bash
cd server
npm install
npm start
```

سرور روی آدرس `http://localhost:4310` بالا می‌آید. فایل‌های دانلود‌شده در
پوشه‌ی زیر ذخیره می‌شوند:

```
~/Downloads/Dashboard-Downloader
```
(در ویندوز: `C:\Users\<نام‌کاربری>\Downloads\Dashboard-Downloader`)

## نکته مهم

پیش از استفاده از بخش «دانلودر» در داشبورد، باید این سرور را روشن نگه دارید.
اگر سرور خاموش باشد، داشبورد پیام خطای اتصال نشان می‌دهد.

برای اجرای خودکار همراه با کل پروژه، می‌توانید از `concurrently` استفاده کنید
یا این سرور را با PM2 به‌صورت سرویس دائمی اجرا کنید.
